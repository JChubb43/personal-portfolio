# Jessie Chubb | Digital Portfolio

This is a personal portfolio website for Jessie “Jay” Chubb, a computer science and digital media student. It introduces Jay’s interests, skills, education, selected projects, and ways to get in touch.

## Features

- Responsive portfolio layout for desktop and mobile screens
- About, skills, education, projects, and contact sections
- Dedicated projects page with links to selected work
- Smooth navigation links that jump to each section
- Project links for Worm Warriors and Grey’s Pest Control Logo
- Accessible image descriptions and navigation labels
- Material Icons for skill badges

## Built With

- HTML5
- CSS3
- Google Material Icons

No build tools, frameworks, or JavaScript are required.
